# RentTrace
Full Project Abstract (For Technical Reports, Submissions & Patent/Research Documentation)  Problem: Urban housing markets suffer from severe information asymmetry. While aggregate listing platforms display current listing prices and historical trends, tenants and homebuyers lack transparency regarding why prices fluctuate, leaving them vulnerable to arbitrary rent hikes and speculative pricing.  Methodology & Architecture: RentTrace aggregates multi-source municipal and macroeconomic data (central bank interest rates, national housing indices, metro expansion milestones, and commercial density shifts) into an integrated geospatial analytics pipeline. Using machine learning regression models paired with SHAP (SHapley Additive exPlanations), the platform calculates feature attribution values for each micro-market, decomposing volatility into exact basis points and monetary impacts per driver.  Civic Impact & Utilities: Rather than operating as an institutional financial terminal, the platform surfaces insights through an accessible, citizen-first interface. Key capabilities include:  Attribution-Driven Locality Audits: Interactive spatial maps detailing neighborhood fair-value benchmarks alongside the infrastructure triggers influencing current rates.  Rent-Hike Legitimacy Engine: A formal benchmarking tool that compares landlord hike demands against local economic fundamentals to generate dispute-ready audit reports.  Total Outflow & Affordability Modeling: Practical financial planning modules accounting for hidden recurring society overheads, commute-to-rent trade-offs, and statutory wear-and-tear depreciation guidelines.
